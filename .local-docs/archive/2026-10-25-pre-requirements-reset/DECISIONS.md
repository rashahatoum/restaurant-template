# القرارات المهمة

## 2026-09-27 — App Router هو نمط التوجيه

- **القرار:** استخدام Next.js App Router داخل `src/app`.
- **السبب:** هذا هو الأساس الفعلي للمشروع ويتيح Server Components وMetadata على مستوى التخطيط والصفحات.
- **البدائل:** Pages Router غير مستخدم في المشروع.

## 2026-09-27 — Server Components افتراضيًا

- **القرار:** تبقى الصفحات والتخطيطات Server Components، ويضاف `"use client"` فقط للمكوّن الذي يحتاج تفاعل المتصفح.
- **السبب:** تقليل JavaScript المرسل للمتصفح والحفاظ على حدود واضحة للتفاعل.
- **التطبيق الحالي:** `NavBar` عميل بسبب `useState`؛ `layout` و`page` خادمان افتراضيًا.

## 2026-09-27 — العربية وRTL من جذر المستند

- **القرار:** ضبط `lang="ar"` و`dir="rtl"` في `RootLayout`.
- **السبب:** العربية هي اللغة الأساسية وتطبيق الاتجاه من الجذر يمنع تكراره داخل المكوّنات.

## 2026-09-27 — إعداد المطعم مركزي

- **القرار:** حفظ بيانات الهوية القابلة للتغيير في `src/config/restaurant.ts` قدر الإمكان.
- **السبب:** تسهيل إعادة استخدام القالب لمطاعم مختلفة وتقليل انتشار قيم الهوية في المكوّنات.
- **البديل:** كتابة بيانات المطعم مباشرة داخل كل صفحة أو مكوّن، وهو غير معتمد.

## 2026-09-27 — الثيم يعتمد على design tokens

- **القرار:** اختيار الثيم عبر `data-theme` وربط CSS variables بأسماء Tailwind دلالية في `globals.css`.
- **السبب:** فصل ألوان العلامة عن المكوّنات القابلة لإعادة الاستخدام.

## 2026-09-27 — ذاكرة المشروع محلية حاليًا

- **القرار:** إبقاء `AGENTS.md` و`.local-docs/` خارج Git في المرحلة الحالية.
- **السبب:** هذه تعليمات وذاكرة تعاون محلية، وقد يعاد تقييم ما يُشارك منها عند انضمام فريق.

## 2026-10-02 — الشاشة الأولى تعتمد على التدفق الطبيعي ومحاذاة مشتركة

- **القرار:** يتشارك `NavBar` و`Hero` غلاف شاشة Flex وpage gutter واحدة، وتُرتب صورة الـHero ومحتواه عبر Flex بدل positional offsets.
- **السبب:** الحفاظ على المحاذاة بين أقسام الموقع وتقليل الأعطال عند تغيير عرض أو ارتفاع الشاشة.
- **البديل:** تداخل الصورة والـNavbar باستخدام absolute positioning وnegative margins، وتم تركه لأنه يحتاج ضبطًا خاصًا لكل قياس.
