# عقد API

## الحالة الحالية

- لا يوجد Backend أو API أو قاعدة بيانات في المشروع.
- لا توجد endpoints أو payloads أو آلية مصادقة متفق عليها.
- بيانات المطعم الحالية محلية في `src/config/restaurant.ts`، وبيانات التواصل فارغة.

## التكامل المستقبلي

Laravel Backend احتمال مستقبلي فقط. لم تتضح بعد حدود البيانات أو العمليات التي ستنتقل إليه، لذلك لا يوجد عقد API يمكن توثيقه دون اختراع متطلبات.

يُحدّث هذا الملف عندما تصبح حاجة تكامل محددة وواضحة، وقبل التنفيذ يُسجّل على الأقل:

- العملية أو مورد البيانات المطلوب من الواجهة.
- شكل الطلب والاستجابة وحالات الخطأ.
- متطلبات المصادقة إن وجدت.
- مصدر الحقيقة وحدود مسؤولية Frontend وBackend.
