# تعريف المشروع

## فكرة المنتج

قالب واجهة عربية لمطعم، مبني بـ Next.js، يقدّم هوية المطعم ومعلوماته وقائمته ومسارًا واضحًا للطلب. الإعداد الحالي يستخدم مطعم "أهل الكرم" كمحتوى فعلي، مع إبقاء بيانات الهوية والثيم مركزية لتسهيل إعادة استخدام القالب لمطاعم أخرى.

## المستخدمون

- زائر عربي يريد معرفة المطعم، تصفح القائمة، الوصول إلى الموقع أو معلومات التواصل، ثم بدء الطلب.
- مالك أو مطوّر المطعم الذي يخصّص الاسم والشعار وSEO وبيانات التواصل والثيم لمطعم مختلف.

## نطاق MVP

الموجود حاليًا هو أساس الواجهة فقط. الـMVP المستهدف، وفق الروابط والإعدادات الموجودة، يتكوّن من:

- صفحة رئيسية عربية ومتجاوبة تعرّف بالمطعم.
- أقسام "من نحن" و"موقعنا" و"تواصل معنا".
- صفحة قائمة طعام على المسار `/menu`.
- وسيلة طلب مباشرة عبر واتساب بعد توفير بيانات التواصل.
- تخصيص أساسي لهوية مطعم آخر من إعداد مركزي وdesign tokens.
- Metadata أساسية قابلة للتخصيص لمحركات البحث.

## مسارات المستخدم المستهدفة

هذه المسارات تعبّر عن هدف الـMVP، وليست كلها منفذة الآن:

1. يدخل الزائر الصفحة الرئيسية ويشاهد هوية المطعم والتنقّل.
2. ينتقل إلى معلومات المطعم أو موقعه أو التواصل من روابط الصفحة.
3. يفتح `/menu` لتصفح الأصناف.
4. يبدأ طلبًا عبر واتساب عند اكتمال بيانات المطعم وتدفق الطلب.

## قابلية إعادة الاستخدام

- `src/config/restaurant.ts` يجمع حاليًا الاسم والشعار وSEO والتواصل والثيم وخيارًا للـhero.
- `data-theme` وCSS variables يفصلان ألوان الهوية عن المكوّنات القابلة لإعادة الاستخدام.
- قابلية إعادة الاستخدام ما زالت أولية؛ بعض أصول الصور والنصوص والروابط موجودة خارج الإعداد المركزي.

## خارج نطاق MVP حاليًا

- Backend أو API أو قاعدة بيانات.
- لوحة إدارة أو تسجيل دخول وصلاحيات.
- دفع إلكتروني، سلة متكاملة، إدارة الطلبات أو تتبعها.
- عقد Laravel؛ الربط احتمال مستقبلي فقط ولم تُحدّد متطلباته بعد.
